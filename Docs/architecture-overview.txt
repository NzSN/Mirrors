DPM: generated action -> binding session -> one actor permit
        -> actual checkpoint arrival -> park -> observe -> compare
C++/Rust retain OS-thread stacks; Node uses owned worker/message channels.
Application hooks, safe checkpoint placement and observation remain handwritten.
Native phase bridges are application-specific. Gate isolation is a separate seam.

CURRENT QUALIFIED TOPOLOGY
WSL2: clients, supplied-trace local replay, Linux/Bubblewrap Gate.
Windows: mTLS Mirrors service -> Apalache/JVM for live model operations.
Gate workers receive public operations/inputs, not private expected model state.
Broader M4 recovery/enforcement remains a separate roadmap track.
