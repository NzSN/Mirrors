Scope: MirrorECMA `19f6ae6ce8d9b073bef888fc66efc4c49f2a07ab`; the Node control SDK and MirrorECMA integration in MirrorGate `4a8d0d361589059ad72fe52e05789f302b4b65c8`. ## Findings

1. **P2 / MI4 + §9.7 — the synchronous target accepts the asynchronous computer contract.** `MirrorECMA/src/negotiated.ts:226` accepts either computer contract, and only rejects the async-target/sync-contract direction. `mirrorecma-v1` plus `mirrors.async-state-computer/v1` is accepted through the callback-selection API (selection without an `execution` field). The registry faithfully finds that exact but invalid pair (`src/adapter-registry.ts:99–103`, `121–125`); a valid matched reply then reaches factory creation and replay (`src/negotiated.ts:550–596`). This violates the documented target/contract pairing and allows application construction for a local configuration that should have been refused. Explicit `execution: "sync"` separately rejects the pair (`815–822`), so its acceptance differs by public overload. Normal compiler-owned configurations are unaffected. Minimal fix: make both pairing directions explicit in callback admission before transport acquisition and add a zero-factory, zero-send negative test. Source-confirmed; scripted runtime probe requested from parent.

## Guide ambiguity requiring reconciliation

**C5 versus §10 / asynchronous connection reuse.** `MirrorECMA/src/connection.ts:447` throws a typed queue-full or registration failure but deliberately leaves the connection usable. `op()` recovers the request queue (`391–397`). This contradicts a literal reading of C5's new-connection requirement after `register_error`. However, §10 explicitly calls `register_error` terminal “for that register attempt,” and the parent independently identified the server's `dispatchAsync` queue-full path (`Mirrors/Shell/Mirror/Session.lean:900–904`) as retaining the connection; the other audited clients do the same. Closing the connection would also cancel unrelated jobs submitted on it under C6. This is a guide/server/SDK contract discrepancy, not an established ECMA runtime defect. Reconcile the normative guide with actual async session semantics before recommending a client behavior change. Existing error tests (`test/async.test.ts:230–253`) assert typed failure but do not pin post-rejection reuse.

## Positive source evidence

- Base transport bounds count final encoded UTF-8 bytes, enforce 65,535 bytes before decoding, reject invalid UTF-8 and unterminated EOF, normalize CRLF, and discard buffered records after framing errors (`src/transport.ts:44–54`, `125–208`). Replay sends one state for each initialization/action and stops immediately on mismatch or terminal errors (`src/replay-core.ts:111–194`). Integer encoding and prototype-looking record keys are retained (`src/protocol.ts:364–402`).
- Inline source resolution recursively walks `EXTENDS` and `INSTANCE`, skips strings/comments, resolves ambiguity and deduplicates dependencies (`src/spec.ts:35–91`, `128–171`). Bounds and async job operations preserve long-poll status and unknown-job termination (`src/connection.ts:132–135`, `158–166`, `299–364`). No direct Apalache fallback appears in the inspected trace-generation/client paths.
- TLS is fixed to 1.3; CA authorization, SAN-only hostname/IP checks and DER-leaf fingerprint pins precede exposure of a transport (`src/transport.ts:431–479`). POSIX keys reject group/other access (`367–375`). Registry retries retain the configured/registry pin (`src/registry.ts:137–150`).
- Negotiation uses duplicate-aware bounded raw parsing and exact versioned object fields; descriptors enforce canonical identity and the 32,768-byte bound (`src/model-interface.ts:1302–1455`, `1495–1516`, `1628–1633`, `879–881`). Required failures and exact digest matching precede factory calls. Explicit preferred fallback remains separate. Binding validation and cleanup retain the primary failure (`src/negotiated.ts:373–478`, `499–630`).
- Dynamic handler registries require exact stable IDs and digest, aliases map to the same action, all input projection precedes dispatch, observations are encoded after one serial observation pass, and failures poison the binding (`src/dynamic-binding.ts:437–482`, `636–707`). Cache reads recompute canonical bytes/digest and quarantine corruption (`src/descriptor-cache.ts:146–177`).
- Structured reports distinguish submitted/matched states and transitions, cap retained coverage with dropped-event counters, freeze snapshots, and encode integers via ITF (`src/replay-report.ts:47–55`, `174–244`). Tests assert immutability, bigint preservation, counts on mismatch, timer/abort suppression of late results and exactly one closure (`test/replay-report.test.ts:28–105`, `116–144`; `test/async-replay.test.ts:32–118`).
